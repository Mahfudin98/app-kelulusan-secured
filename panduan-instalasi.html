Panduan Instalasi Server

Panduan langkah demi langkah mempublikasikan Aplikasi Kelulusan Sekolah di cPanel atau hPanel Hosting Anda.

1
Persiapkan Database MySQL

Pertama, Anda harus membuat database kosong untuk menyimpan data aplikasi:

  1. Login ke cPanel Anda.
  2. Cari dan buka menu MySQL® Database Wizard.
  3. Masukkan nama database baru (misalnya: `kelulusan`), klik Next Step.
  4. Buat user database baru beserta password yang aman.
  5. Centang pilihan ALL PRIVILEGES untuk memberikan hak akses penuh ke user tersebut, lalu klik Make Changes.
  6. Catat info penting ini: Nama Database, User Database, dan Password Database.
2
Unggah File Project

Unggah semua file aplikasi ke folder public domain Anda:

  1. Buka menu File Manager di cPanel.
  2. Masuk ke direktori domain Anda (biasanya `public_html` atau direktori subdomain Anda).
  3. Klik Upload di menu atas dan pilih file zip aplikasi.
  4. Setelah upload 100%, klik kanan file ZIP tersebut di File Manager dan pilih Extract.
  5. Pastikan struktur file telah terekstrak dengan benar di dalam folder tujuan Anda.
💡
Aplikasi menggunakan folder public sebagai document root. Untuk keamanan terbaik, pastikan domain utama/subdomain Anda diarahkan langsung ke folder public di dalam folder ekstraksi tersebut.
3
Konfigurasi Domain & Redirection

Jika hosting cPanel Anda tidak memperbolehkan mengubah document root domain utama dari `public_html` ke `public_html/public`, Anda dapat menggunakan file `.htaccess` bawaan untuk menangani redirection:

  1. Aplikasi ini sudah dilengkapi dengan file `.htaccess` di root direktori dan di dalam direktori `public` untuk melakukan redirection secara aman ke folder public secara otomatis.
  2. Pastikan file tersembunyi (dotfiles) terlihat di cPanel dengan menekan tombol Settings di kanan atas File Manager, lalu centang Show Hidden Files (dotfiles).
4
Setup Aplikasi & Aktivasi Lisensi

Setelah file diunggah dan diarahkan dengan benar, jalankan setup otomatis melalui browser Anda:

  1. Buka browser dan akses domain Anda (contoh: `https://domainanda.com`). Anda akan dialihkan secara otomatis ke halaman setup `/setup`.
  2. Isi formulir instalasi yang tersedia:
    • Nama Aplikasi: Judul aplikasi kelulusan sekolah Anda.
    • URL Aplikasi: Alamat URL domain aktif Anda saat ini.
    • Konfigurasi Database: Masukkan Host (biasanya `127.0.0.1` atau `localhost`), Port (`3306`), Nama Database, User, dan Password database yang Anda buat pada Langkah 1.
    • Email Pembelian: Masukkan email Anda yang terdaftar pada lisensi sistem.
  3. Klik Install Aplikasi Sekarang.
  4. Sistem akan memverifikasi email lisensi ke server pusat, men-setup file konfigurasi `.env`, memigrasi struktur tabel database, dan mengaktifkan aplikasi secara instan.
1
Buat Database MySQL di hPanel

Buat database baru di dashboard Hostinger Anda:

  1. Login ke akun Hostinger (hPanel) Anda.
  2. Masuk ke kelola hosting domain Anda, lalu buka menu Databases → MySQL Databases.
  3. Masukkan nama database, username database baru, dan kata sandi database.
  4. Klik Create.
  5. Catat kredensial database Anda (Nama database dan username hPanel biasanya memiliki prefix unik seperti `u123456789_namaDB`).
2
Unggah File Melalui File Manager

Ekstrak berkas aplikasi ke folder direktori tujuan di hPanel:

  1. Buka menu File Manager di dashboard hPanel.
  2. Masuk ke folder domain Anda, lalu buka public_html.
  3. Unggah file zip aplikasi kelulusan Anda di sana.
  4. Klik kanan pada file zip tersebut dan klik Extract. Anda bisa mengekstraknya langsung di dalam folder root domain.
3
Sesuaikan Folder Publik Utama

Karena Hostinger hPanel mendukung pengaturan direktori publik utama dengan mudah:

  1. Buka menu Websites → Domains di panel hosting.
  2. Pilih subdomain atau domain yang digunakan, lalu ubah Document Root-nya menjadi terarah ke folder `/public` (misalnya: `public_html/public`).
  3. Simpan konfigurasi tersebut. Ini adalah metode paling aman agar file backend inti tidak dapat diakses secara langsung oleh pengunjung.
4
Jalankan Wizard Instalasi

Setup aplikasi Anda dengan mudah:

  1. Kunjungi alamat domain Anda di browser web.
  2. Sistem secara otomatis mengarahkan Anda ke wizard instalasi grafis.
  3. Lengkapi data konfigurasi nama situs Anda, koneksi MySQL yang baru dibuat di Hostinger, dan email lisensi Anda.
  4. Tekan tombol install dan tunggu proses instan selesai. Aplikasi Anda siap digunakan!

Troubleshooting & Pertanyaan Umum

⚠️ Database Connection Error (Koneksi Database Gagal)
Pastikan Host database Anda diset ke 127.0.0.1 atau localhost. Periksa kembali prefix username dan nama database Anda. Di beberapa hosting (seperti Hostinger), prefix wajib disertakan (contoh: u123456_dbkelulusan).
⚠️ Aktivasi Gagal / Hubungi Admin
Pastikan domain Anda sudah bisa diakses online secara publik agar server lisensi pusat dapat memverifikasi validitas domain Anda. Email yang dimasukkan harus sama persis dengan email pendaftaran lisensi Anda.
⚠️ Error 500 saat membuka Halaman Utama
Periksa log PHP di server Anda (storage/logs/php_errors.log). Pastikan ekstensi PHP openssl dan curl telah diaktifkan di konfigurasi cPanel/hPanel (menu Select PHP Version → Extensions).
